# All-but-Crafting

**‘All-but-Crafting!’** improves crafting in *7 Days to Die* by making recipes more logical and visually accurate. Surviving the apocalypse should make more sense.


*I suffered through the details, so you can make more details.*

## Info

This mod changes many crafting recipes, but not all. Some recipes were left as they are for balancing reasons or because they didn’t need adjustments.

## Main Tweaks

- **Recipe Organization**: Two recipes were moved to the Basics page in the crafting menu for easier access.
- **Visual Accuracy**: Many recipes were adjusted to better match the visual model of the items instead of using the default guesswork.

## Installation

1. Download the latest version of the mod from this repository.
2. Open your *7 Days to Die* folder and find the "Mods" folder. If you don’t have one, create a new folder and name it "Mods".
3. Open the Downloaded Zip File
4. Copy the downloaded file(s) into your Mods folder in your *7 Days to Die* installation directory.
5. Launch the game and enjoy smarter crafting!

## Q&A

1. "Is this balanced enough for the game?"

As I go through my list of recipes, I can see SEVERAL differences in recipe cost compared to the base game.
I have thought about this many times while tweaking recipes, and I'm not quite sure whether it's completely balanced or not.
As stated, this mod aims to improve recipes by making them more logical and visually accurate, not balanced.

2. "Why not just leave the crafting system as it is?"

I've played the game quite a bit, though probably not as much as many of you. When I thought the crafting in the game was a bit too dull or had little importance,
I felt inspired to change it. I also noticed many logical flaws appear in the game when you really take a closer look.

3. "Why are some recipes different from the base game?"

I wouldn't say the recipes are very different from the base game, but there are some significant differences.
Most recipe changes either made sense to me or were logical when you considered questions like, **"How big are the materials used in the target recipe?"**

4. "Why are some items unchanged while others were overhauled?"

When I examined the many recipes the game offers, I found that some made sense. Besides that, I left most building recipes alone.
Reviewing all of them would be a huge hassle, even more than what the mod has already provided for me.

5. "Why create custom items like the Gun Kit instead of using existing resources?"

The Gun Kit was my way of saying, "This game has limited resources, and some Gun models have parts they shouldn't for their recipe"
If I added a custom item, it was probably for a reason.

6. "Why focus on realism and visual accuracy rather than game balance?"

I thought there were too many logical flaws in several recipes.

7. "Why do you think players would want this mod instead of just playing vanilla?"

This mod is not necessary for players. To me, it's a quality of life mod. It makes some things easier while making easier tasks more challenging.

8. Why are some recipes more complicated than others after the overhaul?

I adjusted several recipes to match their visual design better. Some previously simple recipes were improved, while some overly complex ones were simplified after careful thought.

Example: Stun Baton

Original Level 1 Recipe:
- Stun Baton Parts × 1
- Forged Iron × 5
- Duct Tape × 2
- Electric Parts × 2

Revised Recipe:
- Stun Baton Parts × 1
- Forged Iron × 3
- Cloth × 1
- Electric Parts × 2
- Mechanical Parts × 2

While the revised recipe adds an extra material, it makes more sense with the crafting process and the roles of the components. This change makes crafting feel more realistic, which my mod aims to do.
