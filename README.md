# All-but-Crafting

**‘All-but-Crafting!’** improves crafting in *7 Days to Die* by making recipes more logical and visually accurate. Surviving the apocalypse should make more sense.


*I suffered through the details, so you can make more details.*

## Info

This mod changes many crafting recipes, but not all. Some recipes were left as they are for balancing reasons or because they didn’t need adjustments.

## Main Tweaks

- **Recipe Organization**: Two recipes were moved to the Basics page in the crafting menu for easier access.
- **Visual Accuracy**: Many recipes were adjusted to better match the visual model of the items instead of using the default guesswork.

## Installation

1. Download the latest version of the mod from this repository.
2. Open your *7 Days to Die* folder and find the "Mods" folder. If you don’t have one, create a new folder and name it "Mods".
3. Copy the downloaded file(s) into your Mods folder in your *7 Days to Die* installation directory.
4. Launch the game and enjoy smarter crafting!

## Notes

- This mod works with other mods, but conflicts may happen if they also target the same recipes.
- If you’re unsure whether the mods will work together, feel free to try them.
- If you find a recipe that seems off or could be improved, let me know!
- Feedback and suggestions are welcome!

If you find any problems related to this mod, please [open an issue here](https://github.com/Feioa/AbC/issues).
